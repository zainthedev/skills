# Lesson text moves from the native language into the target language

Explicit instruction helps (Norris and Ortega 2000), and a beginner cannot read an explanation in the language they are learning. An advanced learner gains from every sentence being input. lingo writes the authored parts of a lesson in the learner's native language at A0 to A2; at B1 the overview, assignment lines, prompts and answers move into the target language while the introduction and core idea stay native; from B2 everything authored is in the target language. Fixed labels and lesson zero stay in English.

## Consequences

- The style lint holds English prose only, so it runs on a part only when that part is native and the native language is English. Target-language text and other native languages are held to STYLE.md by judgement.
- `context.ts` prints the split for each item, so a research pass does not work it out.
