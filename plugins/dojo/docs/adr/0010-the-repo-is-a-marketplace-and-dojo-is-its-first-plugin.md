# The repo is a marketplace; dojo is its first plugin

The repository is a Claude Code plugin marketplace named `zainhill`, with dojo under `plugins/dojo/` and room for more plugins, rather than a single-plugin repo like Matt Pocock's. Teammates on Claude Code add the marketplace once and install only the plugins they want. On every other harness, skills.sh walks the repo for SKILL.md files up to five directories deep, so the same folders install one skill at a time without any change to the layout (ADR 0011). Everything is MIT, copyright Zain Hill. The Odin Project's content is CC BY-NC-SA 4.0, so dojo borrows its structure and philosophy, links to its lessons as resources, and never copies its text. Where Matt Pocock's MIT-licensed text is copied, his notice travels with it.
