# The repo is a marketplace; dojo is its first plugin

The repository is a Claude Code plugin marketplace named `zainhill`, with dojo under `plugins/dojo/` and room for more plugins, rather than a single-plugin repo like Matt Pocock's. Teammates install with one marketplace add and one install command, and the layout keeps every SKILL.md discoverable by skills.sh. Everything is MIT, copyright Zain Hill. The Odin Project's content is CC BY-NC-SA 4.0, so dojo borrows its structure and philosophy, links to its lessons as resources, and never copies its text. Where Matt Pocock's MIT-licensed text is copied, his notice travels with it.
